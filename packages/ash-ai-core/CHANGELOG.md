# Changelog

## 1.0.0 — 2026-11-08

First portable ASH AI Core snapshot taken from the working ASH Chat platform.

Includes provider registration, free-first routing, prompt and context clipping, calculator, Wikipedia and instant-answer research, a memory store contract, lexical embeddings, and optional PDF/OCR extraction.

Does not include accounts, the ASH Chat user interface, SQLite, Postgres, or Supabase.

Products pin this version. Editing the canonical copy does not update a project until that project copies or links a new version.
