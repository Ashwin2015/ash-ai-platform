What you can install today

On Android Chrome, open the hosted ASH Chat site and use Add to Home screen. That installs the web app. It is not a Play Store app and it is not an APK.

Installing an APK outside the Play Store

Android will warn you. Install only a file you downloaded from the ASH Chat site over HTTPS, and check its checksum before you open it. Do not install a debug build. The app must talk to the hosted backend over HTTPS and must not contain API keys.

Chat, accounts, research, and cloud models need a network. The installed shell can open offline. It cannot answer as if the model were on the phone.
